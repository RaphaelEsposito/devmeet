Les besoins et les choix :

Le public visé est tout public c'est pourquoi je l'ai très épuré et simple. Le but de DevMeet est d'avoir un site pour connaître les différentes conférences et les horaires.
Les couleurs choisis sont des couleurs qui sont souvents ensembles et qui collent à ce que je veux faire.

La démarche :

J'ai commencer par écrire le code HTML en premier et ensuite je suis passé au css pour avoir en premier la structure et ensuite l'affichage.

J'ai choisi pour le tableau de faire une colonne pour les horaires, la conférence et la description car je n'arrivais pas à faire ce que je voulais avec les lignes donc j'ai du changer de système.

Lancement :

- npm ci (Récupérer les dépendances)

- npm run build (Build l'app)

Explications techniques : 

J'ai utilisé des Flexbox pour le tableau car je trouvais que cela coller mieux pour ce que je souhaitais faire.
